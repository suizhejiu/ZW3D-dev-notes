# ZW3D 二次开发踩坑记录：官方文档不会告诉你的失败场景

> 内容说明：本文是一份个人复盘，记录用 ZW3D 官方 C/C++ 插件 API 做批量建模时遇到的问题。
> 所有结论都附了实测数据，不含任何厂商文件或商业内容。

---

## 一、先说结论

用 ZW3D 插件 API 建了 37 个零件，过程中遇到十来个“调用返回成功但结果不对”的情况。
这些坑官方文档基本没写，整理出来供后来者参考。

**先说最重要的一条**：**`ZW3dRemote` 返回 `OK`、API 返回 `0`，都不代表操作真的生效。**

---

## 二、十个官方文档没写的坑

### 1. `-10000` 的真实含义

`cvxSkAddPolyline` / `cvxSkSpline` 返回 `-10000`，这个码不在标准 `evxErrors` 列表里。

**实测**：唯一场景是“**没有调用 `cvxSkActivate(sk, 0)` 进入草图**”。

```c
int sk = 0;
cvxPartSkNew(&m, &sk);
cvxSkActivate(sk, 0);        // ★ 这一步不能省

cvxSkAddPolyline(n, pts, 0); // 这时才返回 0

cvxRootExit();
cvxSkActivate(0, 0);         // 这个只是退出
```

`cvxSkActivate(0,0)` 是“退出到零件级”，不是“进入草图”。混淆这两个，几何永远画不进去。

### 2. `cvxRootExit()` 会弹空草图确认框

如果草图里没画上几何，`cvxRootExit()` 会弹「是否删除空草图」的对话框。

在自动化流程里这会**直接阻塞执行**，而且如果点了“否”，几何被丢弃，后续拉伸返回 `-152`。

**对策**：保证草图里确实有几何再调它，或者只用 `cvxSkActivate(0,0)` 退出。

### 3. 所有草图必须在第一次拉伸前建好

一旦拉伸生成实体，活动根从“零件”变成“实体”，此时再 `cvxPartSkNew` + 画几何会失败。

**正确顺序**：

```c
// 草图 A
cvxPartSkNew(&mA, &skA); cvxSkActivate(skA, 0);
cvxSkAddPolyline(...); cvxRootExit();

// 草图 B（此时零件根仍然活动）
cvxPartSkNew(&mB, &skB); cvxSkActivate(skB, 0);
cvxSkSpline(...); cvxRootExit(); cvxSkActivate(0, 0);

// 最后统一拉伸
cvxPartExtrude(&extA, &shA);
cvxPartExtrude(&extB, &shB);
```

### 4. `cvxFileClose()` 不调会假死

连续建 13 个零件不关文档，进程内存涨到 1.2 GB，之后 `ZW3dRemote` 命令**不再响应**
（端口还在监听，但命令发过去没反应）。

加上 `cvxFileClose()` 后，连续跑 14 个零件，内存只涨 24 MB。

### 5. 编译必须加 `/utf-8`

源码里有中文注释时，MSVC 默认按系统代码页（GBK）解析，某些字节被误判成 ASCII 的 `{` 或 `}`，
编译器“看到”了不存在的括号，报出 `C2267` / `C2601` / `C1075` 这类莫名其妙的错误。

**解法**：编译加 `/utf-8`，或者源文件存成 GBK。

### 6. 闭合样条的两个参数缺一不可

```c
svxSplineData sd;
cvxSkSplineInit(&sd, n);
sd.SplineTyp     = 0;   // 通过点
sd.Degree        = 1;   // ★ 1 = 直线段，保留尖角（默认 3 会磨圆）
sd.CreateCrvOpen = 0;   // ★ 0 = 闭合（默认 1 是开放）
sd.Count         = n;
cvxSkSpline(&sd, &sp);
```

少了 `Degree=1`，齿轮齿形会被磨圆；少了 `CreateCrvOpen=0`，曲线不闭合，围不成面。

另外：**点数少于 8 时样条会明显外扩**（4 点的正方形被撑到 1.5 倍），少量点建议用
`cvxSkAddPolyline`。

### 7. 带孔的轮廓要用两条独立闭合曲线

一条曲线走“外圈 + 桥接 + 内圈”的 8 字形，会被判成自交，拉伸体积为 0。

**正确做法**：同一草图里画两条独立闭合曲线，拉伸时 `idProfile` 传**草图 id**（不是曲线 id）。

### 8. 任意平面（含 YZ）不要手填矩阵

这是本项目最大的一个误判。我曾手填 `svxMatrix` 的 12 个分量，YZ 平面怎么也建不出来，
一度判定为“厂商 API 限制”。

**正确做法**：用官方 `zwapi_matrix.h` 的构造函数：

```c
#include "zwapi_matrix.h"

szwPoint  origin = {0, 0, 0};
szwVector zAxis  = {1, 0, 0};        /* 法向世界 X，即 YZ 平面 */
szwMatrix m;
ZwMatrixGetByPointAndZAxis(origin, zAxis, &m);

svxMatrix sm;                        /* szwMatrix 多 4 个字段，显式拷贝 */
memset(&sm, 0, sizeof(sm));
sm.identity = m.identity;
sm.xx = m.xx; sm.yx = m.yx; sm.zx = m.zx; sm.xt = m.xt;
sm.xy = m.xy; sm.yy = m.yy; sm.zy = m.zy; sm.yt = m.yt;
sm.xz = m.xz; sm.yz = m.yz; sm.zz = m.zz; sm.zt = m.zt;

cvxPartSkNew(&sm, &sk);
```

**实测**：XY / XZ / YZ 三个平面全部正确，Ø20 圆柱拉伸 10 的包围盒分别为
`20×20×10`、`20×10×20`、`10×20×20`。

`zwapi_matrix.h` 里有 33 个函数（`ZwMatrixInitByTranslation`、`ZwMatrixInitByRotation`、
`ZwMatrixGetByPointAndXYAxis`、`ZwMatrixCoordinateSystemGet` 等），**先读这个头文件再动手**。

### 9. `cvxPartMoveTransform` 已废弃，但会“假成功”

```c
cvxPartMoveTransform(id, (svxMatrix*)&m);   // 返回 0
```

- 旋转：返回 0，但包围盒完全不变
- 平移：变成“复制 + 移动”，原体还在，包围盒翻倍

官方注释说得很清楚：

> This function will not be updated anymore, please use `ZwFeatureMoveCreateByTransform()`

**建议**：在目标位置直接建模，不要“建完再转”。

### 10. 变量：能建、但可能没写进文件

```c
int count = 0;
szwVariableData *list = NULL;
ZwVariableListGet(NULL, &count, &list);   // 返回 0，但 count = 0
```

`ZwVariableCreate` 返回 0，但事后读变量列表是空的——**“调用没报错” ≠ “真的生效”**。

**另一个坑**：`ZwVariableDelete` 会弹模态对话框，在自动化流程里调用会**直接卡死插件**，
只能强杀进程。不要在脚本里调它。

## 三、参数化：变量绑尺寸是可以做的

这一节是本文最有用的部分。

### 关键 API

```c
cvxSkAddConsDim(...)          /* 在草图里加约束尺寸，拿到尺寸 id */
cvxDimValMod(idDim, "D")      /* 把尺寸值设成变量名（不是数字） */
```

缺了这两个，API 建的几何只能是硬编码的 `double`。

### 实测数据

| 场景 | 结果 |
|---|---|
| D=80, d=25, t=5，圆画 r=40/12.5，尺寸填 `D`/`d` | 体积 **22,678.372** = π(40²−12.5²)×5 |
| 先建 D=100，圆仍画 r=40/12.5，尺寸填 `D`/`d` | 几何**自动跳到 r=50**，体积 **36,815.539** |

**第二行是关键**：说明尺寸框里填变量名确实能驱动几何。

### 三个限制

1. **事后改变量不会自动重建**：`ZwVariableListSet(D=100)` 返回 0，但体积不变
2. **`ZwVariableDelete` 会弹模态框**，卡死插件
3. **变量必须在建几何之前建**

**结论**：不要指望“改变量触发重建”，正确做法是**每个配置完整重跑一遍**：

```
for 每个参数组合:
    新建零件 → 设变量 → 建几何（尺寸绑变量）→ 拉伸 → 导出 → 关闭
```

## 四、工具链小结

### 编译

```bat
call "<VS>\VC\Auxiliary\Build\vcvars64.bat"
cl /nologo /LD /utf-8 /MT /EHsc /O2 /D_CRT_SECURE_NO_WARNINGS ^
   /I"<ZW3D>\api\inc" ^
   MyPlugin.cpp ^
   /link /LIBPATH:"<ZW3D>" ZW3D.lib /OUT:MyPlugin.dll
```

### DLL 位置

```
%APPDATA%\ZWSOFT\ZW3D\<版本名>\custom\apilibs\
```

**不是**安装目录下的 `custom\apilibs`。

### 远程触发

```bat
zw3d.exe -server
ZW3dRemote.exe /R local "cmd=~myCommand"
```

### 错误码速查

| 码 | 含义 |
|---|---|
| `-5` | 无活动根对象 |
| `-6` / `-7` | 单对象文件调了多对象接口 |
| `-31` | 参数为 NULL |
| `-152` | 命令执行失败（常见：草图无几何） |
| `-241` | 文件名含非法字符 |
| `-242` | 文件格式不被接受 |
| `-10000` | **草图未激活**（未调 `cvxSkActivate(sk,0)`） |

## 五、官方资源索引（这段可能是最实用的）

`<ZW3D 安装目录>\api\` 里有一整套资料：

```
├── ApiExample.zip              官方示例，20 个 VS 工程
├── ApiHelpDoc.chm              英文 API 帮助（22 MB）
├── ApiHelpDoc_chs.chm          中文 API 帮助（23 MB）
├── ZW3D API introduction_Chs.pdf
└── DevelopmentTemplate\        工程模板
```

**20 个示例的目录**：

```
1.BaseInquiry          基础查询
2.TopoInquiry          拓扑查询（拿实体 id）
4.FilletBox            倒圆角
5.FileOperation        文件操作（带示例 .Z3）
6.Pattern              阵列
7.CurveCreate          曲线创建
12.DllRegister         插件注册工具
15.EditVariable        变量编辑
17.ExTrudewithPreview  带预览的拉伸
19.MatrixOperations    矩阵操作
20.ChamferAddAndDelete 倒角增删
```

**插件注册有官方工具**：`12.DllRegister`，参数 `-n -a -d -l -r`，不用手动拷 DLL 再界面加载。

## 六、一个教训

本项目前期花了大量时间“试错”，而答案一直在安装目录里。

如果用一句话总结：

> **拿到 SDK 第一件事：清点 `api` 目录，读 CHM，看示例。**
> **遇到 API 问题，先搜文档，再动手试。**
